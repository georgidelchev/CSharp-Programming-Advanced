## 📖 About

This repository contains my complete solutions for the **[C# Programming Basics](https://softuni.bg/trainings/2808/programming-basics-with-c-sharp-march-2020)** course at [SoftUni](https://softuni.bg). The course covers foundational programming concepts through hands-on problem solving, progressing from simple I/O and arithmetic all the way to nested loops and complex conditionals.

Every solution has been submitted to the **Open Judge System (OJS)** and achieved a perfect **100/100** score.

## 🚀 Getting Started

1. **Clone the repository**
   ```bash
   git clone https://github.com/georgidelchev/CSharp-Programming-Basics.git
   cd CSharp-Programming-Basics
   ```

2. **Open any solution** — each folder contains `.sln` or `.cs` files openable in Visual Studio or Rider.

3. **Browse by topic** — navigate to the module folder matching the concept you want to explore.
